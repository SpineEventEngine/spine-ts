## Current State

- Implemented Spine JVM-compatible `D`, `E`, and `V` native namespace
  conversion. Single tenancy preserves the caller client's configured/default
  namespace; multitenancy puts the selected namespace on every key, query, and
  transaction. Bounded Context names no longer enter physical identity.
- Replaced tagged/canonical keys and properties with `DatastoreIdColumn` and
  `DatastoreColumnMapping`: compact Proto JSON/custom stringifiers for message
  IDs and ordinary message columns; native Datastore scalar, integer, double,
  blob, enum, Timestamp, Version, and null values. Write values, query operands,
  and provider continuations use the same declared mapping.
- Deleted the provider-local tagged canonical value codec. Local reconciliation
  now uses the shared storage query-value semantics and stores no replacement
  tag, marker, scope, revision, or compatibility entity.
- Added a factory-owned native namespace catalog over Datastore
  `__namespace__` metadata. Early `keep()` admission is memory-only until the
  provider exposes the namespace; it writes no `TenantId` record.
- Corrected default compact Proto JSON parsing to restore registered canonical
  `Any` type URLs. This preserves message-valued physical keys across
  read/delete and keeps Spine-prefixed application types interoperable while
  well-known types retain their canonical Google URL.
- Migrated the optional emulator contract: Bounded Context names share one
  physical family, `StorageGroup` still selects a distinct kind, and complete
  generated tenants select separate native namespaces.
