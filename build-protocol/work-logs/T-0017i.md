## Implementation Notes

- Durable subscription records use the existing
  `StorageFactory.createRecordStorage()`/`RecordSpec` seam under a
  service-owned non-tenant namespace named `<context>:subscriptions`. Tenant
  identity remains a field in the durable record so one service can scan
  inactive records for activation without per-tenant storage enumeration.
