## Decisions

- Keep this slice focused on metadata factories and narrow local runtime
  integration. Example/testing adoption and semantic tag runtime registration
  are follow-up tasks.
- Inspect Spine JVM docs/source before implementation even where the TS shape
  seems obvious.
- Add a small shared runtime metadata object instead of broad transport,
  storage, tracing, or app-level registration changes. The first adoption
  target is repository-produced signal metadata because this is where framework
  internals currently leak into repeated inline construction.
- Keep the public runtime API small: expose explicit metadata builders and
  deterministic `Clock` / ID injection seams, but avoid containers, service
  registries, or application-owned handler/runtime hooks in this task.
- Keep causal follow-up IDs stable in repository paths. The shared factory owns
  the derivation policy (`source-id` plus sequence) so repository adoption can
  add timestamps and consistent context without broad test churn.
