## Decisions

- Keep this slice narrow: consume existing descriptor-derived semantic tags in
  runtime routing topics; do not introduce a new tag registry, handler
  materializer, delivery behavior, or application-owned API.
- Command topics will use the semantic tags from the command assignee entity
  metadata.
- Event topics will use the deterministic deduplicated union of semantic tags
  from all registered receivers for the event type.
