## Decisions

- Keep this slice focused on subscription service event targets and
  `event_updates`; defer durable subscription recovery, process-manager
  execution, and transport-backed delivery loops.
- Event subscription delivery will use a small framework-internal `EventBus`
  subscriber hook keyed by event type URL. Application dispatchers continue to
  receive domain event messages through existing handler materialization; the
  framework `Event` envelope remains internal to bus/service/runtime code and
  the wire-level `SubscriptionUpdate`.
- Focused fix worker kept subscriber fan-out synchronous inside the existing
  single event-bus runtime queue. This slice has in-process service delivery
  only; the bus snapshots subscribers before fan-out, clones the framework
  `Event` per callback, and isolates callback exceptions, so a larger scheduler
  would be outside the current scope. The small reliability fix is close-time
  subscriber record cleanup: bus shutdown marks direct subscriptions closed,
  clears the subscriber map, and drops callback references.
