## Decisions

- Start from `SignalTransport` and `ZeroMqAdapterConfig`; do not expose ZeroMQ
  details through the package root or server user APIs.
- Keep the first topology local IPC only.
- Keep process supervision, health checks, retry policy, remote transport, and
  broker clustering deferred.
- Use Node's structured binary serializer internally for local IPC envelopes so
  generated protobuf objects and typed-array fields survive the adapter hop
  without exposing multipart frames or socket details.
- Keep ZeroMQ construction adapter-scoped. The package root still exports only
  neutral transport contracts.
