# T-0025 Delivery Label Contract Cleanup

## Summary

- Removed `IMPORT_EVENT` from the public `DeliveryLabel` contract.
- Rejected new `IMPORT_EVENT` writes through `Inbox.receive()` and
  `InboxStorage.write()` before durable storage opens.
- Kept stored/wire `IMPORT_EVENT` recognizable as deprecated compatibility data
  while failing closed before it can be delivered.
- Updated delivery API and architecture docs to describe supported labels and
  the legacy fail-closed behavior.
