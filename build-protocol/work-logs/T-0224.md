## Contract and implementation

- `MessageId` represents a generated Buf `Message`.
- The target Entity ID field supplies the schema used for admission.
- Generated validation runs before durable serialization.
- `Identifiers.pack()` verifies that the complete message is serializable.
- Default Command routing reads the Command's declared first field.
- Event routing prefers a compatible packed producer ID and otherwise reads the
  Event's declared first field.
- State-update routing selects the first state field compatible with the Entity
  ID field.
- Custom routes retain complete message IDs or return a compatible primitive ID
  for a primitive target.
- Inbox targets, persistence keys, producer contexts, route deduplication, and
  dispatch guards continue through descriptor-aware packed identity.
