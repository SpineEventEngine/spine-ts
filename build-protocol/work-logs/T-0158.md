## 2026-08-11 - Review Correction

  `DoubleValue`. Repository-derived identities now use the descriptor-aware
  `EntityIds` mapping shared with current/history records and Inbox targets.
  Generic application-facing `SignalMetadata` number behavior is unchanged.
- Rejection events for message-valued Entity IDs now carry the actual packed
  Entity ID instead of the legacy synthetic `Unknown` producer. The primitive
  reader also accepts JVM-shaped `Int32Value` producer IDs.

  an accepted Aggregate and Process Manager Command, followed by replay of a
  stored typed target without another callback. The route contract is
  documented as deterministic and side-effect-free.

  one callback across independent retries or process restarts would require a
  new command-ID-to-route receipt or marker. Wave 8 prohibits that persistence,

  admission plus no evaluation during replay, so no such mechanism was added.
