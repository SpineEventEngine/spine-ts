# Better Auth native sessions and password login

High-risk native engine integration. The complete TASK ledger, PROPOSAL and
accepted architecture govern this slice. Use exact Better Auth 1.7.16 behavior.

## Contract

BetterAuthIntegration.create exposes sessions, credentials and admitted routes.
SupportedBetterAuthOptions retains native names with the proposal's narrow
allowlist; JavaScript callers receive equivalent construction-time validation.
Reject unsafe secrets/cookies/origins, database overrides, unsupported plugins,
models/hooks/fields, secondary storage and cookie caching. Disable native schema
validation and automatic verification cleanup; the Spine factory prepares data.

Support preprovisioned native password accounts and trusted external verified
login against a complete read-only User directory. A caller-supplied user ID is
not login proof. Map native User to Spine principal explicitly; directory/storage
failure cannot become anonymous success.

RPC resolution invokes native getSession with refresh/cache disabled. An explicit
native renewal route forwards all response cookies and updates only existing
sessions. Replace public native sign-out with strict validated-cookie durable
revocation; stock sign-out cannot bypass failure reporting. Retain expired rows
on normal reads, including the native slow-User-lookup expiry deletion path.

## Acceptance

Exercise real BrowserServer and native Better Auth engine: correct/incorrect
password, external proof, directory failures, restart, renewal/logout in both
orders, durable logout failure, expiry during User lookup and manual cleanup.
Test exact active-secret rollover behavior; do not infer seamless cookie rollover
from retained secret configuration. Connect local stream invalidation to the
shared authenticated session identity. Update public API/configuration examples.

SupportedBetterAuthOptions uses local structural declarations while preserving
native property names, including hashing and rate-rule callbacks. For a generic
OAuth plugin value, validate and detach supported native options before async
initialization and build the installed native plugin from that configuration.
Do not execute caller-provided plugin implementations. Known native implementation
fields are ignored; unknown features/configuration reject. Test mutation during
startup and an injected init/hook that must never execute.
