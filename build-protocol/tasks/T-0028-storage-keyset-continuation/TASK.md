## Objective

Add the smallest storage continuation contract needed for durable delivery
scans to resume after a stable ordered row key, and use it so framework-owned
delivery scans no longer depend on moving absolute pending-row offsets.

## Scope

- Add the smallest `RecordQuery`/`RecordStorage` continuation contract needed
  to page after a stable ordered row key.
- Preserve existing `RecordQuery.offset` support for current storage callers.
- Implement the continuation contract in the in-memory record storage adapter.
- Apply the continuation only to durable inbox pending-row scans used by
  `Delivery` and `DeliveryLoop`.
- Replace delivery scan/resume reliance on absolute moving offsets with
  keyset-style continuation over existing inbox order:
  `receivedAt`, `version`, `messageId`.
- Keep current behavior for supported worker labels:
  `HANDLE_COMMAND`, `UPDATE_SUBSCRIBER`, and `REACT_UPON_EVENT`.
- Keep valid worker-unsupported `CATCH_UP` rows pending/skipped before callback
  invocation, row acceptance, failure recording, and failure-budget
  consumption.
- Keep deprecated legacy `IMPORT_EVENT` rows fail-closed as storage
  corruption.
- Preserve scan bounds, callback limits, failure bounds, shard leases,
  per-message claims, tenant validation, payload validation, and at-least-once
  stale-owner caveats.
- Update public docs and TypeDoc comments to distinguish storage continuation
  from production indexing and storage adapters.

## Out Of Scope

- Production database adapters.
- General query optimizer or index planner.
- New public delivery worker APIs.
- Retry monitors, retained attempt history, retry policy,
  conveyor/station hierarchy, and production worker supervision.
- ZeroMQ endpoint topology, broker/process supervision, or deployment
  hardening.
- Durable catch-up storage or projection catch-up through inbox storage.
- `ImportBus`, aggregate import/importers, aggregate `@Apply`, or new
  `IMPORT_EVENT` writes.
- Removing existing `RecordQuery.offset`.
- Broad automatic storage capability negotiation.
