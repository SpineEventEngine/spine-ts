# Release 3 containment correction

The logging checker found nine detached catches, ten sentinel-fulfilling callbacks, and one stale marker. Each reported catch was inspected against its original promise and its caller before adding an adjacent boundary marker. This correction adds markers and manifest dispositions only; it does not change the catches or a runtime error path.

| Boundary IDs                                                                                              | Why `no-log` is accurate                                                                                                                                                                                                                                            | Existing behavior evidence                                                                                                                                                                                                                                                                             |
| --------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `server.managed_child_deadline_ipc_observer`, `server.managed_child_deadline_close_observer`              | The child records `#shutdownFailure`, releases its close gates, and forces marked-child exit if close remains unsettled. These detached attempts cannot replace the terminal deadline outcome. A disappeared parent's IPC cannot receive a diagnostic.              | `managed-server-application.test.ts`: child deadline and parent IPC tests, including “does not extend an accepted child close deadline after wall-clock rollback.”                                                                                                                                     |
