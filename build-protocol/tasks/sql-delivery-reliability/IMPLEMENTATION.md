## DEL-05 independent SQL record writes and generic CAS — primitive checkpoint

Acceptance for this checkpoint: a failed second record leaves the first write durable; immutable Event retry accepts identical bytes and rejects a conflicting payload; a same-ID immutable race admits one payload; generic CAS compares decoded expected values but guards the atomic SQL write with the observed raw bytes. A failed guard is reread within a bounded retry, while an unrelated unique-key failure and the original driver cause remain visible internally. These rules apply to PostgreSQL 16/18, MySQL 8.4, MariaDB 11.4, and the MyISAM/Aria fixture variants.

Generic CAS reads and decodes the current record to compare the caller's expected value, then uses a single conditional insert/update/delete guarded by ID and the exact observed raw bytes; guard misses reread up to three times.
