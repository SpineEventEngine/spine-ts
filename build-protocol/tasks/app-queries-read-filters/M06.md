transitively using ordinary package resolution. Inspect package metadata and
exports without executing dependency modules. Reuse existing package/model
resolution facilities where suitable; ModelGraph currently follows explicitly
configured Proto packages, which is not the full runtime dependency graph.

Do not analyze dependency TypeScript sources/declarations to rebuild metadata.

still matters for transitive participants. Build workspace dependencies first.

class descriptions, stale metadata, missing published exports/files and unusable

pick one installed version. Package version/path conflicts and exact constructor
identity are different checks and must not be conflated.
